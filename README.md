# Pilotage multi-projets

Exemples de supports de suivi pour un rôle de chef de projet aux côtés d'un directeur technique : portefeuille, planning Gantt, kanban, backlog RICE, registre RAID, attentes client, incidents, indicateurs DORA et trame de point client.

Page statique en un seul fichier (`index.html`), sans dépendance à installer. Ouvrir le fichier dans un navigateur suffit.

Les données sont fictives.
